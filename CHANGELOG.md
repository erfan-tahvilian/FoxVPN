# Changelog

## v1.0.0 — 2026-10-11

First independent Windows x64 release of Fox VPN.

- English desktop UI with orange accents, supplied Fox VPN branding, and light/dark/system themes.
- Firefox Accounts authentication and email verification, encrypted sessions and token refresh.
- Guardian entitlement, proxy pass, quota headers, and live location discovery.
- Authenticated HTTP/2 CONNECT relay, local SOCKS5 and DNS bridge.
- Windows system VPN via a bundled, separately licensed TUN engine and Wintun.
- Executable-based split tunneling, proxy-only mode, HTTP/SOCKS5 upstream chaining, and custom edge.
- Private DNS, DoH provider selection, custom TCP DNS and exit verification.
- Connection statistics, activity log export, tray controls, installer and portable distribution.

See README for service dependencies and transport limitations. Live account acceptance is not covered by the automated fixture tests.
