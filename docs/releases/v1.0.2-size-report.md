The separately uploaded FoxVPN source archive is retired after source-content verification. GitHub's native tag archives remain available. sing-box source and both checksum manifests are retained; see [the asset and dependency audit](v1.0.2-asset-audit.md) and [corresponding source](../../SOURCES.md).
