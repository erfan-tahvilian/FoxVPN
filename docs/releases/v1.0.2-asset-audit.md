## Dependency and runtime review

The desktop application's direct production dependency is pinned `socks`, with its small transitive dependency set. Electron and electron-builder are development/build dependencies; only Electron's required runtime and production dependencies are packaged. `flag-icons` supplies the checked-in country flags and is not a production JavaScript dependency. Build caches, test results, README images, source archives and Git metadata are outside the application package allowlist.

Electron/Chromium is the main desktop payload. All locale resources, rendering and graphics fallbacks, security resources, notices and supported executable architectures remain intact. Removing those files could change compatibility, accessibility or graphics behavior. Replacing Electron, downgrading dependencies or modifying the sing-box feature set is outside a lossless packaging change. Go native outputs already use stripped debug information and trimpath in the existing build; UPX and custom executable packers are not introduced.

The Android package is dominated by the native Go/VPN library. Existing ABI splits, extracted native-library packaging and 16 KiB ELF compatibility are retained. R8/obfuscation, resource shrinking, JNI pruning and changing Go build tags are not used in this update because they alter runtime code and require broader acceptance than archive preservation. Dependency versions and the native VPN implementation are unchanged apart from the application's version metadata.

## Applied compression and proof

- Windows ZIP uses the pinned builder's maximum Deflate preset, including its multi-pass search, while retaining native Explorer extraction. This takes more build CPU time. The NSIS solid-archive compression was already level 9 in v1.0.1 and stays enabled.
- macOS native ZIP uses level 9 and preserves symlinks. Existing DMG compression stays UDBZ.
- Linux retains xz AppImage and the existing DEB/RPM compression families. Archive-wide level 9 is selected where supported by the pinned builder; no unverified package-manager flags are added.
- Android unsigned release ZIP entries are recompressed with standard Deflate level 9. Every entry's SHA-256, compression method and attributes must match, then zipalign runs and architecture/16 KiB validation runs again. Larger candidates are rejected. Signing happens afterward with the persistent identity; existing v1/v2/v3 signature policy is retained.
- Every Windows EXE/ZIP, macOS DMG/ZIP and Linux AppImage/DEB/RPM is extracted on a matching native CI host and compared with its original complete app payload, including symlinks and executable permissions.
- Windows records original portable entries before NSIS adds its installer-specific elevation helper; comparison uses the final file hashes. Linux records its original application before DEB/RPM add their format-specific metadata. These format-specific additions are not mistaken for missing portable runtime files.

Archive compression can change build and extraction time. No installed runtime file is removed to produce an artificial size reduction. Installed footprint and sustained VPN throughput are not claimed to improve. Exact per-file savings, including any small increases, are reported separately from removed duplicate release assets.

## Source, licensing and update safety

[SOURCES.md](../../SOURCES.md) identifies the exact Fox VPN source and retained sing-box source. Both current native source and the historical custom maintenance archive are compared against their exported Git commits before publication. The historical source is linked by its maintenance commit instead of incorrectly pointing to the earlier version tag. Existing license text, notices and engine provenance remain bundled. Source availability follows [GPLv3 section 6(d)](https://www.gnu.org/licenses/gpl.en.html); the distributor remains responsible for equivalent access even when linking another server.

The update mechanism chooses assets by platform, architecture and package format, checks release digests and downloads only after the user chooses. All 21 existing asset name patterns are retained. Custom FoxVPN source archives are not installation/update inputs, build caches or signing inputs. The sing-box source archive is not executable runtime input, but is retained for corresponding-source access. Neither SHA256 manifest is removed.

Native-host build and package checks cannot establish physical-device behavior on every supported OS and architecture. Physical Windows installation and Android ARM64 delivery are recorded after publication; no claim of physical macOS/Linux acceptance is made.
