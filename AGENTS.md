# Fox VPN workspace preferences

- After building and publishing a new Windows release, install that latest release locally at `D:\Program Files\FoxVPN` and verify the installed version. The user explicitly requested this installation path for every future release.
- Keep the application UI in English, with orange dark and light themes and country flags beside locations.
- Do not display references to FoxyVPN or Vauth in the application UI. Preserve required third-party license notices in the license files.

- Keep the application, installer, source metadata and GitHub release version at `v1.0.0` for all current updates. Do not increment the version unless the user explicitly requests it. Replace the existing v1.0.0 release assets with the latest verified build and install it at the preferred path.
